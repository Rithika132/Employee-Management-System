# Employee-Management-System
Employee Management System is a web-based CRUD application developed to manage employee information efficiently. The system allows users to add, view, update, and delete employee records such as name, email, phone number, department, position, salary, and joining date. The application uses HTML, CSS, and JavaScript for the frontend .

2. Front-End:
HTML – Web page structure
CSS – Styling and responsive design
JavaScript – User interaction and API communication
The frontend provides forms and displays employee records in an easy-to-use interface.

3. Back-End:
Python
Django
Django REST Framework
The backend handles business logic, CRUD operations, data validation, and REST API requests.

4. Database:
SQLite
SQLite is used to store employee information such as name, email, phone, department, position, salary, and joining date.

5. Key Features:
•Add new employee records
•View employee details
•Update employee information
•Delete employee records
•Email validation
•Unique email checking
•REST API integration
•Database storage
•User-friendly interface

6. Advantages:
•Easy to manage employee records
•Reduces manual data management
•Quick access to employee information
•Simple and user-friendly
•Provides reliable CRUD operations
•Easy to maintain and extend
•Frontend and backend are connected through REST APIs

7. CRUD Operations:
Create – Add a new employee
Read – View employee records
Update – Modify employee details
Delete – Remove employee records

8. Technologies Used:
Frontend: HTML, CSS, JavaScript
Backend: Python, Django, Django REST Framework
Database: SQLite
API Testing: Postman
IDE: Visual Studio Code
Version Control: Git & GitHub

9. Project Outcome:
The project provides a complete web-based solution for managing employee information. It demonstrates frontend development, backend development, database integration, REST API communication, validation, and CRUD functionality in a single application.
